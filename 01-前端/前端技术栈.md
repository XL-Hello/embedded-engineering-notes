# RTOS 开发中的前端技术栈

这里的“前端”指运行在设备端的图形用户界面（GUI）与人机交互界面（HMI）。本文仅罗列直接服务于界面构建、视觉呈现、交互设计和 UI 测试的技术栈关键词，不包含 RTOS 内核、通信协议、显示驱动或硬件调试工具。

## 1. 界面开发语言与描述

- **C / C++**：嵌入式 GUI 组件、界面逻辑、事件回调
- **QML / JavaScript**：Qt Quick 界面描述、状态逻辑、动画

## 2. GUI / HMI 框架

- **LVGL**：Widgets、Style、Flex、Grid、Animation
- **Qt for MCUs / Qt Quick**：QML、信号与槽、状态机、Scene Graph
- **TouchGFX**：Designer、MVP、Canvas Widget
- **SEGGER emWin**：窗口管理、控件、皮肤（Skin）
- **GUIX**：GUIX Studio、Widget、Canvas
- **uGFX、µC/GUI、Persimmon、Slint**：轻量级或商业嵌入式 GUI
- **Crank Storyboard**：富媒体 HMI

## 3. 图形渲染与视觉效果

- **2D 图形**：绘制（Draw）、裁剪（Clip）、透明混合（Alpha Blending）、图层（Layer）
- **图像资源**：BMP、PNG、JPEG、GIF、SVG、WebP、RLE
- **字体与文字**：FreeType、位图字体、TTF / OTF、字库裁剪、Unicode、UTF-8、中文显示
- **动画**：帧动画、补间动画（Tween）、缓动曲线、Lottie、转场动画
- **图形加速 API**：OpenGL ES
- **帧渲染与防撕裂**：双缓冲、三缓冲、局部刷新、脏矩形（Dirty Area）、帧率控制、VSync、TE（Tearing Effect）信号、帧同步（Frame Pacing）

## 4. 用户交互与界面行为

- **触摸交互**：单点触摸、多点触摸、手势识别、触摸校准
- **输入方式**：按键、旋钮、编码器、鼠标、键盘、遥控器
- **输入事件**：点击、按下、抬起、滑动、长按、拖拽、焦点切换
- **界面交互**：页面导航、弹窗、软键盘、列表滚动、焦点管理
- **可用性**：大字体、高对比度、蜂鸣器 / 震动反馈、误触防护

## 5. 资源、主题与国际化

- **资源管理**：图片 / 字体打包、二进制资源、资源清单、按需加载
- **界面设计工具**：SquareLine Studio、TouchGFX Designer、Qt Design Studio、GUIX Studio
- **主题系统**：颜色表、Style、暗色模式、皮肤（Skin）、分辨率适配
- **国际化**：i18n、l10n、多语言、文本 ID、字库压缩、RTL（从右到左）布局

## 6. UI 数据呈现与状态

- **数据可视化**：仪表盘、折线图、柱状图、波形图、告警、趋势曲线
- **界面状态**：数据绑定、发布订阅（Pub/Sub）、状态同步、缓存、实时刷新

## 7. UI 性能与测试

- **UI 性能指标**：帧率（FPS）、界面刷新耗时、响应延迟、界面启动时间
- **UI 性能优化**：局部重绘、资源压缩、字体裁剪、降低过度绘制
- **UI 测试**：UI 自动化测试、截图比对、交互事件模拟、压力测试、长稳测试

## 8. 常见前端组合

- **轻量级 MCU UI**：LVGL + SquareLine Studio
- **ST 图形界面**：TouchGFX + TouchGFX Designer
- **富交互 HMI**：Qt Quick + Qt Design Studio

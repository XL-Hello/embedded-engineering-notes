# 嵌入式工程笔记

一份面向**嵌入式软件工程实践与面试复习**的个人知识库。内容以 MCU / RTOS / Linux 嵌入式方向为主，覆盖从 Cortex-M 内核、总线接口、RTOS 与中间件，到 GUI 前端、调试排障、设计模式和项目复盘的完整链路。

笔记的写法偏向**工程结论而非教科书罗列**：每篇先说清「这是什么、解决什么问题、边界在哪」，再展开原理、代码和排查手段，多数主题配有手绘风格的技术示意图。

## 使用约定

- **文档与配图同级**：每篇 `X.md` 的示意图统一放在同级的 `X/` 目录中，移动文档时需连同图片目录一起移动。
- **版本后缀**：同一主题存在多个不同版本时，以 `-v2` 后缀区分（如 `Modbus.md` 与 `Modbus-v2.md`），内容完全重复的文件不予保留。
- **配图风格**：技术示意图统一采用工程笔记式手写风格，细则见 [配图规范](00-导航与索引/配图规范.md)。
- **占位目录**：尚未填充内容的分类保留空目录与 `.gitkeep`，用于标记后续补全方向（算法、Makefile / CMake、交叉编译、工业数据采集、物联网网关等）。

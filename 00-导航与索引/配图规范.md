# 技术图文配图规范

## 默认字体风格（强制）

技术图文配图中的中英文、数字、单位与公式说明，统一采用**工程笔记式手写技术字体**。该风格以 `项目/总结/总线接口/LIN/6-LDF定义到波形验证-v2.png` 为视觉基准；它是视觉样式，不指定某个可安装的字体文件。

- 中文：清晰、端正的手写工程标注感；笔画略有自然粗细变化，但不得潦草或艺术化。
- 英文、数字与单位：与中文一致的手写技术风格；字母、数字、`0x`、`kbit/s`、`μs`、`Byte` 等必须清晰易辨。
- 标题、正文、图注、表格与流程标签均使用同一字体家族感；允许以字号、字重和颜色区分层级，不得混入无衬线印刷体、宋体、圆体或另一种手写风格。
- 以技术可读性优先：字距稳定、字符不粘连、表格内不溢出；中英文混排保持基线协调。

## 生成图片时的固定约束

在图片生成提示词中加入以下约束：

```text
Typography (required): use the engineering-notebook handwritten technical lettering style of the reference image `项目/总结/总线接口/LIN/6-LDF定义到波形验证-v2.png`. Apply one coherent handwritten technical font style to all Chinese, English, numbers, units, labels and table text. Keep text crisp, legible, and suitable for an engineering document. Do not use printed sans-serif, serif, rounded UI fonts, calligraphy, or mixed font families.
```

## 修改既有图片时的固定约束

若只要求调整字体，必须同时加入以下不变量，避免重绘图形或破坏技术含义：

```text
Change only typography. Preserve all text content verbatim, and preserve all non-text elements unchanged: canvas size, layout, positions, line breaks, icons, waveform traces, connecting lines, arrows, boxes, table grids, borders, colors, dimensions, spacing, and background. Do not add, remove, move, resize, redraw, recolor, or alter any non-text content. No watermark or logo.
```

若修改图片中已有字体，应将上述 LIN 图 6 作为字体风格参考图，仅迁移字体风格，不得复制其文字、图形或布局。

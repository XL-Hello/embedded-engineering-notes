# 四寸屏
## 1.LCD
围绕AWTK前端、LCD驱动、显示原理等方面总结本项目的要点，同时补充可能的面试问题。
- 本项目的显示接口是什么？讲一下原理？你还知道哪些常用的其他嵌入式显示接口？

提示：标准的 MIPI DSI 2-Lane 显示接口
```c
/*
 * LCD Interface: MIPI DSI 2-Lane
 *
 * BES2600                         LCD Panel
 * ------------------------------------------------
 *
 *  MIPI_CLKP  ------------------>  DSI_CLKP
 *  MIPI_CLKN  ------------------>  DSI_CLKN
 *
 *  MIPI_D0P   ------------------>  DSI_D0P
 *  MIPI_D0N   ------------------>  DSI_D0N
 *
 *  MIPI_D1P   ------------------>  DSI_D1P
 *  MIPI_D1N   ------------------>  DSI_D1N
 *
 *  LCD_RST    ------------------>  LCD Reset
 *
 * ------------------------------------------------
 * Description:
 *  - The LCD uses a MIPI DSI display interface.
 *  - The interface is configured as 2 data lanes + 1 clock lane.
 *  - MIPI_D0P/N and MIPI_D1P/N are high-speed differential data lanes.
 *  - MIPI_CLKP/N is the high-speed differential clock lane.
 *  - LCD_RST is used to reset the LCD panel or LCD driver IC.
 *  - MIPI CSI pins are not used in this project.
 *
 * Signal List:
 *  - MIPI_CLKP / MIPI_CLKN : DSI clock differential pair
 *  - MIPI_D0P  / MIPI_D0N  : DSI data lane 0 differential pair
 *  - MIPI_D1P  / MIPI_D1N  : DSI data lane 1 differential pair
 *  - LCD_RST              : LCD reset control
 */
```
答：

本项目的显示接口是 **标准 MIPI DSI 2-Lane 显示接口**。

从硬件连接看，主控 BES2600 到 LCD 屏主要使用以下信号：

- `MIPI_CLKP / MIPI_CLKN`：MIPI DSI 时钟差分对。
- `MIPI_D0P / MIPI_D0N`：MIPI DSI 数据 Lane 0 差分对。
- `MIPI_D1P / MIPI_D1N`：MIPI DSI 数据 Lane 1 差分对。
- `LCD_RST`：LCD 复位控制脚，用于复位屏幕或屏幕驱动 IC。

也就是说，本项目不是并口 RGB、SPI 屏，也不是 LVDS/eDP 屏，而是 **1 组差分时钟 Lane + 2 组差分数据 Lane** 的 MIPI DSI 屏幕。这里的 `2-Lane` 指的是有两条高速数据通道，带宽比 1-Lane 更高，适合四寸屏这类分辨率和刷新率要求更高的显示场景。

### 1. MIPI DSI 2-Lane 的基本原理

MIPI DSI，全称是 **Mobile Industry Processor Interface Display Serial Interface**，是移动设备和嵌入式设备中常用的高速串行显示接口。它的核心思想是：

- 主控内部的 LCDC / Display Controller 先生成一帧图像数据。
- DSI 控制器把图像数据按照 MIPI DSI 协议打包成数据包。
- 数据通过高速差分信号发送到 LCD 屏的驱动 IC。
- 屏幕驱动 IC 解析 DSI 数据包，再控制 LCD 面板逐行刷新显示。

MIPI DSI 主要有两类传输内容：

- **命令数据**：用于初始化屏幕，比如退出睡眠、设置像素格式、设置显示方向、打开显示等。
- **图像数据**：用于传输 framebuffer 中的像素内容，比如 RGB565、RGB888 等格式的像素流。

在电气层面，MIPI DSI 使用差分信号传输：

- 差分信号抗干扰能力强。
- 串行传输减少了引脚数量。
- 高速模式下可以提供较高显示带宽。
- 低功耗模式下可以发送初始化命令或控制命令。

所以它很适合小尺寸、中高分辨率、对引脚数量和 EMI 比较敏感的嵌入式显示产品。

### 2. 2-Lane 的含义

本项目使用的是 **MIPI DSI 2-Lane**：

- `Clock Lane`：负责提供 DSI 高速传输时钟。
- `Data Lane 0`：传输一部分显示数据。
- `Data Lane 1`：传输另一部分显示数据。

两条 Data Lane 可以并行传输像素数据。相比 1-Lane，2-Lane 的有效带宽更高；相比 4-Lane，2-Lane 的 PCB 布线和硬件成本更低。对四寸屏来说，2-Lane 通常是比较均衡的选择。

面试时可以这样概括：

> 本项目 LCD 使用标准 MIPI DSI 2-Lane 接口，包含一组差分时钟线和两组差分数据线。主控通过 DSI 控制器把显示控制命令和 framebuffer 像素数据封装成 MIPI DSI 数据包，经高速差分 Lane 发送给屏幕驱动 IC，由屏幕驱动 IC 完成解析和刷新显示。2-Lane 表示有两条高速数据通道，能够在较少引脚数量下提供足够的显示带宽。

### 3. 常见的其他嵌入式显示接口

常见嵌入式显示接口主要有下面几类：

| 接口 | 特点 | 常见场景 |
| --- | --- | --- |
| `SPI` | 引脚少、成本低、速度相对较慢 | 小尺寸屏、低刷新率 UI、手环、仪表小屏 |
| `8080 MCU 并口` | 并行数据线，速度比 SPI 快，占用 GPIO 多 | 中小尺寸 TFT 屏、传统 MCU 项目 |
| `RGB 并口` | 直接输出 RGB 数据、行同步、场同步、像素时钟 | 裸屏、无显存屏、工业屏、低成本 Linux 显示 |
| `MIPI DSI` | 高速串行差分、引脚少、带宽高 | 手机屏、智能硬件、中高分辨率 LCD |
| `LVDS` | 差分传输、抗干扰强、传输距离比 MIPI 更友好 | 工控屏、车载屏、较大尺寸 LCD |
| `eDP` | 基于 DisplayPort，带宽高、功能完整 | 笔记本屏、高分辨率嵌入式屏 |
| `HDMI` | 标准外部显示接口，兼容性强 | 外接显示器、开发板、机顶盒 |

### 4. 这些接口的简单区别

- `SPI`：最省引脚，但刷新速度有限，不适合高分辨率高帧率屏。
- `8080 MCU`：比 SPI 快，但需要较多数据线和控制线。
- `RGB`：数据实时并行输出，接口简单，但引脚多，对时序要求明显，通常需要屏端配合。
- `MIPI DSI`：引脚少、速度快，是移动和智能设备常用方案，但协议和驱动初始化更复杂。
- `LVDS`：抗干扰强，适合较远距离或较大屏幕，但一般硬件链路比 MIPI DSI 更偏显示模组/工控场景。
- `eDP/HDMI`：更偏高分辨率通用显示，协议复杂，常用于更高端或外接显示场景。

本项目选择 MIPI DSI 2-Lane，主要是为了在较少引脚数量下满足 LCD 的显示带宽需求，同时利用差分高速串行传输提升抗干扰能力和布线友好性。

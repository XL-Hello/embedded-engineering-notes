# 嵌入式 ADC 数据采集 基础

> 目标：从“模拟电压如何变成程序中的数字”这个主线理解 ADC。先讲最简单的电位器采集电路，再扩展到常用传感器，并总结项目调试和面试中容易忽略的问题。
>
> 核心结论：**ADC 不是直接测量物理量，而是在规定参考电压、输入范围和采样时刻下，把引脚上的模拟电压量化为有限位数的数字码；传感器采集的关键是先把温度、压力、光照等物理量稳定地转换成 ADC 可接受的电压。**

## 1. 一句话理解 ADC

`ADC` 是 Analog-to-Digital Converter，即模数转换器。它把连续变化的模拟电压转换为 MCU / SoC 能计算和存储的整数。

```text
真实物理量
  温度 / 光照 / 压力 / 电池电压 / 电流
        |
        v
传感器或前端电路输出模拟电压
        |
        v
ADC 在某一时刻采样并量化
        |
        v
数字码 raw
        |
        v
软件换算、滤波、校准、阈值判断
        |
        v
温度值 / 电压值 / 控制决策
```

例如 12 bit ADC 有 `2^12 = 4096` 个码值，通常原始结果范围是 `0 ~ 4095`。若 ADC 参考电压为 `3.3 V`、输入范围为 `0 ~ 3.3 V`，则电压与码值可近似理解为：

```text
raw ≈ Vin / Vref × (2^N - 1)
Vin ≈ raw / (2^N - 1) × Vref
```

其中：

- `Vin`：ADC 引脚在采样瞬间的实际输入电压。
- `Vref`：ADC 的参考电压，决定满量程对应多少伏。
- `N`：ADC 分辨率，例如 10 bit、12 bit、16 bit。
- `raw`：ADC 转换得到的原始数字码。

这里的公式用于理解和工程换算。实际芯片还要看数据手册中 ADC 的满量程定义、偏移误差、增益误差、校准方式和有效位数。

## 2. ADC 内部在做什么

可以把一次 ADC 转换拆成三个动作：采样、保持、量化编码。

```text
模拟输入 Vin
    |
    v
采样开关闭合：给内部采样电容充电
    |
    v
采样开关断开：保持采样瞬间的电压
    |
    v
比较 / 量化：确定最接近的数字码
    |
    v
输出 raw
```

### 2.1 采样与保持

ADC 输入端通常存在采样开关和很小的采样电容。采样时间内，外部信号通过信号源阻抗给该电容充电；转换时开关断开，ADC 对保持住的电压进行比较。

因此 ADC 不是“无限阻抗、完全不取电”的理想电压表。若外部信号源阻抗太大，或采样时间太短，采样电容来不及充到真实 `Vin`，结果通常偏低或随通道切换而波动。

```text
传感器输出 -- Rs --+--> ADC 采样开关 --> Csample
                    |
                    +--> 可选 RC 滤波电容
```

这也是为什么很多 MCU 的数据手册会给出“不同 ADC 时钟 / 采样时间对应的最大推荐源阻抗”。

### 2.2 量化：连续电压变成离散台阶

以理想 3 bit ADC 为例，`0 ~ Vref` 被分成 8 个量化区间，只能输出 `0 ~ 7` 中的一个整数。输入电压连续变化，但输出会一级一级跳变。

```text
Vin:  0V ------------------------------ Vref
raw:  0 | 1 | 2 | 3 | 4 | 5 | 6 | 7
```

理想情况下，最低有效位 `LSB` 对应的电压约为：

```text
LSB ≈ Vref / 2^N
```

例如 `Vref=3.3 V`、12 bit 时，1 LSB 约为 `0.806 mV`。这只表示码宽，不等于系统真的能稳定分辨 `0.806 mV`：噪声、参考电压误差、ADC 非线性和前端误差都会降低实际有效分辨率。

### 2.3 常见 ADC 架构

MCU 内置 ADC 最常见的是 `SAR ADC`（逐次逼近型）：它通过内部 DAC 和比较器，从高位到低位逐步判断每一位，速度、功耗和成本比较均衡。

```text
采样保持 -> 先判断最高位 -> 再判断下一位 -> ... -> 得到 N bit 结果
```

此外还常见：

- `Sigma-Delta ADC`：过采样后数字滤波，分辨率和低频精度高，转换延迟相对大；常见于高精度称重、音频和测量场景。
- `Flash ADC`：大量比较器并行工作，速度很高，但功耗和面积大。
- 外置 ADC：当内置 ADC 的通道数、精度、输入类型或抗干扰能力不够时使用，常通过 I2C、SPI 等数字接口读数。

## 3. 最简单电路：电位器采集电压

最容易理解 ADC 的方式，是用电位器产生一个可变电压。

```text
      3.3 V
        |
       [ 电位器 ]
        |
        +-------> ADC_IN
        |
       GND
```

电位器两端接 `3.3 V` 和 `GND`，中间滑动端接 ADC 输入。旋钮位置改变时，滑动端电压在 `0 ~ 3.3 V` 连续变化。

若使用 12 bit ADC：

```text
旋钮最靠近 GND       -> Vin ≈ 0 V   -> raw ≈ 0
旋钮在中间           -> Vin ≈ 1.65V -> raw ≈ 2048
旋钮最靠近 3.3 V     -> Vin ≈ 3.3V  -> raw ≈ 4095
```

软件读取和换算逻辑可以写成：

```c
#define ADC_MAX_CODE  4095.0f
#define ADC_VREF      3.3f

float adc_raw_to_voltage(uint16_t raw)
{
    return (float)raw * ADC_VREF / ADC_MAX_CODE;
}
```

完整数据流：

```text
旋钮位置
  -> 分压比例变化
  -> ADC_IN 电压变化
  -> ADC raw
  -> 软件换算为 voltage
  -> 用于显示或控制
```

### 3.1 最简单电路也要注意什么

- ADC 输入电压不能超过芯片规定范围，通常不能高于 `VDDA / Vref+`，也不能低于 `VSS / GND`。
- 数字电源噪声会直接影响参考电压和 ADC 结果；不能只看“满量程是 3.3 V”。
- 电位器阻值不宜无限大。阻值很大时，滑动端源阻抗变大，可能需要增加 ADC 采样时间或在前端加缓冲。
- 输入端可视情况加小 RC 滤波，但电容过大、源阻抗过大都会让响应变慢，也可能影响多通道快速扫描。
- 未连接的 ADC 通道会漂浮，读数随机，不能作为有效数据。

## 4. 从 raw 到真实物理量

ADC 只给出电压对应的 raw，传感器采集还需要一层“电压与物理量的关系”。

```text
物理量 X
  -> 传感器输出 Vin
  -> ADC raw
  -> Vin
  -> 根据传感器模型换算 X
```

典型软件分层：

```text
adc_read_raw(channel)       : 读取硬件原始码
adc_raw_to_voltage(raw)     : raw -> 引脚电压
sensor_voltage_to_value(v)  : 电压 -> 温度/压力/光照等
filter_and_decide(value)    : 滤波、校准、阈值和控制
```

将这些步骤分开，能明确定位问题：是 ADC 本身不准、前端电压不对，还是传感器模型 / 标定参数有问题。

## 5. 常用传感器采集原理

### 5.1 NTC 热敏电阻：电阻变化 -> 分压 -> 温度

NTC 的特点是温度升高、电阻下降。MCU 不能直接读电阻，通常把 NTC 与固定电阻组成分压电路。

```text
Vref
 |
[ Rfixed ]
 |
 +-------> ADC_IN
 |
[ NTC ]
 |
GND
```

以图中连接方式为例：

```text
Vadc = Vref × Rntc / (Rfixed + Rntc)
```

温度升高时，`Rntc` 变小，`Vadc` 也变小。软件先由 ADC 求出 `Vadc`，再反算 `Rntc`，最后通过 NTC 的 `Beta` 参数公式或查表得到温度。

```text
温度变化
  -> NTC 阻值变化
  -> 分压电压变化
  -> ADC raw
  -> 反算 NTC 阻值
  -> 查表 / Beta 公式
  -> 温度值
```

工程上常用查表加线性插值，因为实现简单、运行快，也能直接使用器件厂商提供的阻温表。需要注意 NTC 是非线性的，不能仅用一个固定比例把 raw 当温度。

### 5.2 光敏电阻：光照变化 -> 分压 -> 相对亮度

光敏电阻 `LDR` 的阻值随光照变化，常见情况下光越强、电阻越小。连接方式与 NTC 类似：用固定电阻构成分压，再用 ADC 读取中点电压。

```text
光照变化 -> LDR 阻值变化 -> 分压变化 -> ADC raw -> 光照等级 / 控制策略
```

LDR 的一致性、温漂和响应速度通常不适合高精度照度计；做自动背光、昼夜判断等功能时，更适合按实测 raw 标定若干阈值，并加入回差和时间滤波，避免临界亮度下反复切换。

### 5.3 模拟电压型温湿度、压力、气体传感器

有些传感器模块已经完成了敏感元件、放大和补偿，直接输出 `0~Vref`、`0~3.3 V`、`0.5~4.5 V` 或比例式电压。

```text
物理量
  -> 传感器内部敏感元件
  -> 放大 / 补偿
  -> 模拟输出电压
  -> ADC
  -> 按数据手册公式换算
```

例如某压力传感器定义：`0.5 V` 对应 0 kPa、`4.5 V` 对应满量程。若 MCU ADC 只能接受 `0~3.3 V`，则不能直接连接，必须通过分压、运放缩放或选择合适供电 / 输出范围，使任何异常情况下 ADC 引脚都不越界。

面试时要强调：**不是看到“模拟输出”就能直接接 ADC，先核对输出范围、供电、共地、参考电压和故障时最大电压。**

### 5.4 电池电压采集：高电压 -> 电阻分压 -> ADC

电池电压经常高于 ADC 输入范围，因此通常使用两只电阻分压：

```text
VBAT
 |
[ Rtop ]
 |
 +-------> ADC_IN
 |
[ Rbottom ]
 |
GND
```

```text
Vadc = Vbat × Rbottom / (Rtop + Rbottom)
Vbat = Vadc × (Rtop + Rbottom) / Rbottom
```

实际设计要同时满足：

- 最大电池电压、充电电压和浪涌时，`Vadc` 仍在 ADC 允许范围内。
- 电阻不能太小，否则静态耗电大；也不能太大，否则源阻抗高、漏电和采样电容影响明显。
- 分压点可以加电容滤波；需要低功耗时可用 MOS 管或 GPIO 控制分压器，仅在采样时接通。
- 注意 ADC 钳位电流。即使串联电阻存在，异常电压也不能长期依赖内部 ESD 二极管承受。

### 5.5 电流采集：分流电阻 -> 放大 -> ADC

最常见思路是在电流回路串一个很小的分流电阻 `Rshunt`：

```text
负载电流 I -> Rshunt 上产生 Vshunt = I × Rshunt
                       |
                       v
                 电流检测放大器
                       |
                       v
                      ADC
```

因为 `Vshunt` 通常只有毫伏级，为了充分利用 ADC 量程，常使用运放或专用电流检测放大器放大。高边采样的共模电压较高，不能简单用普通运放代替，需确认输入共模范围；低边采样电路简单，但会抬高负载地电位，可能影响其他测量和通信。

这里最容易混淆的三个量是：分流电阻压降、放大器输出电压、最终换算出的电流。排查时要按这条链路逐点测量。

### 5.6 4~20 mA 工业电流环：电流 -> 采样电阻 -> 电压 -> ADC

工业现场常用 `4~20 mA` 传输信号。ADC 不能直接读电流，通常使用精密采样电阻，例如 `250 ohm`：

```text
4 mA  × 250 ohm = 1.0 V
20 mA × 250 ohm = 5.0 V
```

再根据 ADC 量程选择合适电阻或缩放电路。`4 mA` 不对应零电流，而是“活零点”：可用于区分正常最小量程与断线 / 设备故障。若要做工业级设计，还需要考虑隔离、防浪涌、共模干扰和精密电阻误差。

## 6. 多通道、DMA 与采样频率

MCU 常把多个 ADC 通道按规则轮流采样：

```text
CH0 -> CH1 -> CH2 -> ... -> CHn -> 再回到 CH0
```

常见实现是定时器触发 ADC，ADC 用 DMA 把结果搬到内存：

```text
定时器固定周期触发
  -> ADC 扫描多个通道
  -> DMA 写入循环缓冲区
  -> 任务读取一帧数据、滤波和换算
```

优点是采样周期稳定、CPU 开销小，也避免在任务中用不精确的 `delay` 轮询。

多通道扫描要注意：相邻通道会受采样电容残留电压影响，尤其是“高阻信号 + 很短采样时间 + 前后通道电压差大”时。处理方法包括：增加采样时间、降低前端阻抗、增加缓冲运放、调整通道顺序，或在切换通道后丢弃第一次采样结果，具体取决于芯片数据手册和实测。

采样频率不是越高越好。它至少要满足信号带宽和控制响应要求；若要准确保留某个最高频率成分，理论上采样频率应高于其两倍，工程上通常还要留余量并配置模拟 / 数字滤波，防止高频噪声混叠到低频。

## 7. 滤波、平均与校准

ADC raw 抖动并不一定是 ADC 坏了，可能是传感器噪声、电源纹波、开关电源、地弹、数字 GPIO 翻转或信号本身在变化。

### 7.1 常用数字处理

- 均值滤波：连续取 N 个样本平均，简单有效，但响应变慢。
- 中值滤波：对偶发尖峰有效，适合按键、电位器或受干扰的慢变化信号。
- 一阶 IIR：`y = y + alpha × (x - y)`，RAM 占用小、响应可调。
- 限幅 / 异常值剔除：先拒绝明显不可能的跳变，再进入正常滤波。
- 滞回：阈值上升和下降使用不同门限，避免临界点抖动导致反复开关。

滤波不是越强越好。温度显示可慢一些，过流保护则需要更快响应；必须从功能的响应时间和安全要求出发选择采样周期、窗口长度和阈值。

### 7.2 校准解决什么问题

理想公式默认 `Vref`、电阻和 ADC 都准确，实际会有：

- 参考电压误差和温漂。
- ADC 偏移误差、增益误差、非线性。
- 分压电阻误差、传感器批次差异。
- PCB 漏电、接触电阻和自热。

常见校准方式包括：

- 零点校准：已知输入为零或基准点时，记录 offset。
- 两点校准：使用两个已知点求线性关系 `value = k × raw + b`。
- 多点查表 / 拟合：适合 NTC 等明显非线性的传感器。
- 使用内部参考通道：有些 MCU 可测内部基准电压，用于估算实际 VDDA；具体方法必须以芯片手册为准。

校准参数应明确单位、版本和生效范围。若保存到 Flash，还要考虑掉电保护、校验和参数升级兼容。

## 8. 项目中常见问题与排查

| 现象 | 可能原因 | 排查重点 |
| --- | --- | --- |
| 读数恒为 0 或满量程 | 引脚模式、通道号、参考电压、硬件短路 / 开路错误 | 万用表测 ADC 引脚电压；检查 GPIO 是否为模拟模式 |
| 读数明显偏大或偏小 | Vref 不准、分压比例错、换算公式错、校准缺失 | 对比已知电压和 raw；逐段验证分压与软件公式 |
| 读数抖动 | 电源 / 地噪声、采样频率不合适、信号高阻、无滤波 | 示波器看 ADC 引脚和 Vref；增加采样时间后对比 |
| 多通道互相影响 | 通道切换残留、源阻抗高、采样时间太短 | 改通道顺序、丢首样、加长采样时间 |
| 低压端不为 0 | 地线压降、偏移误差、传感器输出下限不为 0 | 区分 ADC 地、传感器地和系统大电流回流 |
| 电压正常但换算物理量不对 | 单位、模型、查表或传感器方向错误 | 记录 raw、Vin、中间电阻值和最终结果 |
| 特定动作时异常 | PWM、电机、无线发射或屏幕刷新引入干扰 | 关联时序；检查模拟地、去耦、走线与采样时刻 |

推荐排查顺序：

```text
先测 ADC 引脚真实电压
  -> 再看 ADC raw 是否与该电压匹配
  -> 再核对 raw -> 电压公式
  -> 再核对 电压 -> 物理量模型 / 标定
  -> 最后才调滤波和阈值
```

不要一看到数据跳动就先加很大的平均滤波；那可能把硬件问题隐藏起来，同时让控制响应变慢。

## 9. 硬件设计注意点

- **输入范围**：包括正常最大值、充电值、浪涌和故障值都不能超过 ADC 绝对最大额定值及推荐工作范围。
- **参考电压**：Vref 就是测量标尺。若 Vref 来自噪声很大的电源，结果会随电源波动；高精度场景应使用合适基准源、去耦和布局。
- **源阻抗与采样时间**：高阻分压、NTC 和传感器输出都要匹配 ADC 采样电容的充电时间。
- **RC 滤波**：靠近 ADC 的小串阻和电容可以抑制高频噪声，但要同时检查带宽、稳定时间和多通道扫描影响。
- **地与布局**：模拟小信号远离电机、DC/DC 电感、高速时钟和大电流回路；模拟地回流路径要清晰，不能让大电流回流穿过测量基准。
- **保护**：外部接口或长线传感器需要考虑串阻、TVS、RC、防反接和 ESD；保护器件的漏电也可能影响高阻测量。
- **量程利用**：尽量让正常信号占 ADC 满量程的大部分，以获得更好的有效分辨率，但要留足异常裕量。

## 10. 面试常见问题与回答要点

### 10.1 ADC 分辨率 12 bit 是什么意思？

表示 ADC 可把输入范围量化为约 4096 个数字等级，raw 通常为 `0~4095`。在 `3.3 V` 参考下，理想码宽约 `3.3 / 4096 = 0.806 mV`。但不能直接说测量精度就是 0.806 mV，还要考虑参考电压、噪声、线性误差和有效位数。

### 10.2 为什么 ADC 读数会抖？如何处理？

先区分信号真实变化和测量链路噪声。检查 ADC 引脚、Vref、电源地、采样时间、源阻抗、布局和干扰源；硬件没有明显问题后，再按实时性选择均值、中值、IIR、限幅和滞回。不能只靠软件平均掩盖问题。

### 10.3 为什么分压电阻不能随便选很大？

电阻很大虽能降低静态功耗，但会提高源阻抗。ADC 采样时内部电容充电变慢，采样时间不足会导致误差；同时 PCB 漏电、输入漏电和噪声影响更明显。需要在功耗、精度、采样时间和前端电容之间权衡。

### 10.4 ADC 的采样时间和转换时间有什么区别？

采样时间是采样电容跟随外部输入、完成充电的时间；转换时间是 ADC 对保持电压进行量化得到数字码的时间。高阻信号主要要求足够的采样时间。总转换周期通常由采样时间、转换时间及触发 / DMA 等链路共同决定。

### 10.5 如何测量高于 ADC 输入范围的电池电压？

用电阻分压或合适的模拟前端把最大电压缩放到 ADC 输入范围内，再根据分压比反算电池电压。设计时按最大充电 / 异常电压校核输入范围，同时平衡分压功耗与源阻抗，并考虑保护和校准。

### 10.6 多通道 ADC 为什么会串扰？

多路 ADC 通常复用同一个采样保持电路。通道切换后采样电容仍保留前一通道电压；若新通道源阻抗高或采样时间短，就不能快速稳定到新电压。可增加采样时间、降低源阻抗、加缓冲、优化采样顺序或丢弃首样。

### 10.7 ADC 和 DAC 的区别？

ADC 是模拟量转数字量，用于采集；DAC 是数字量转模拟电压 / 电流，用于输出控制、波形生成等。两者都受参考电压、量化和模拟误差影响，但数据流方向相反。

## 11. 项目回答模板

> 项目中 ADC 采集的对象是 `XXX`。硬件上先通过 `分压 / 传感器模拟输出 / 放大电路` 把信号转换并限制在 ADC 的输入范围内；软件由定时器周期触发 ADC，使用 DMA 获取原始码。随后按实际参考电压和前端比例换算为电压，再结合传感器特性查表或公式得到物理量。为解决抖动，我先确认了 ADC 引脚、电源和采样时间，再采用 `XXX` 滤波，并针对控制阈值加入回差。对于量产一致性，使用 `零点 / 两点 / 查表` 标定，并把校准参数保存和校验。

回答时要能继续解释四件事：

- 采样对象的输出范围是多少，为什么不会超过 ADC 输入范围。
- 前端电阻、RC、放大器或保护电路为什么这样选。
- 采样周期、采样时间、DMA 和滤波为什么满足业务实时性。
- 实测出现偏差或抖动时，如何从 ADC 引脚电压到最终物理量逐级定位。

## 12. 关键结论

```text
物理量
  -> 传感器 / 分压 / 放大前端
  -> ADC 输入电压 Vin
  -> 采样保持
  -> 量化得到 raw
  -> raw 换算为电压
  -> 校准、查表或传感器公式
  -> 滤波、阈值和控制决策
```

- ADC 测的是引脚电压，不是温度、压力或电量本身。
- `Vref`、分辨率和输入范围决定 raw 与电压的基本关系。
- 高阻信号必须关注采样电容和采样时间，否则公式正确也会测错。
- 传感器采集的核心是“物理量 -> 可测、稳定、安全的电压 -> 合适的算法换算”。
- 项目排查应从真实引脚电压开始，依次检查 ADC raw、换算、标定和业务逻辑。
- 面试中不要把 LSB 当成绝对精度；要主动说明参考源、噪声、误差、校准和系统设计。

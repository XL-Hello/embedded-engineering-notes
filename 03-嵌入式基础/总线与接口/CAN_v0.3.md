# CAN 进阶：从一个位算到一条总线

> 本文件当前仅为结构骨架，各节内容待逐章填充。
>
> 系列分工：本篇是 CAN 系列的第三篇。前两篇是《CAN 基础知识总结》（CAN.md，以下称 v0.1）与《CAN FD 和 CAN XL 基础知识总结》（CAN FD、CAN XL.md，以下称 v0.2）。v0.1 回答"是什么、怎么用、不通怎么查"，v0.2 回答"三代差在哪、能不能混用、怎么选"，本篇回答"**怎么算**"。
>
> 主线：**把一条 CAN 总线从一个位算到整网负载**。晶振决定位时间，位时间决定采样点，采样点错了产生错误帧，错误帧累加改变总线状态，单帧时长与重传共同决定总线负载与最坏响应时间——这是一条完整的因果链，章节顺序即这条链的顺序。
>
> 范围收敛：本篇只做"可计算的部分"。凡是无法落到公式、表格或判据上的内容（上层协议、驱动实现、网络架构、功能安全）一律不在本篇，见 v0.4 或另立文档。
>
> 前置：读者已理解差分与显隐性、ID 与仲裁、帧字段构成、终端电阻的作用，以及 CAN FD 的双速率机制。
>
> 写作约定：
>
> 1. 每章开头写明"本章解决什么工程决策"，结尾写明"本章产出什么可检查结果"，产出必须是一份**可填写、可核对的表格**。
> 2. 跨篇引用一律用主题名，写作"见 v0.1〈某某〉"或"见 v0.2〈某某〉"，不写章节号。
> 3. 全篇围绕第 1.4 节的同一个网络展开，第二～七章反复回到它。
> 4. 涉及具体数值处标注"以控制器手册为准"或"由项目填写"，不给脱离场景的绝对值。

## 第二章、位时间模型：从晶振到一个位

> 本章解决的工程决策：理解一个位是怎么被切分出来的，以及采样发生在哪一刻。
>

### 2.1、从晶振到时间量子

- 控制器时钟源与预分频的关系，时间量子的定义
- 为什么 CAN 的位时序用"量子个数"而不是直接用时间描述

### 2.2、一个位被分成四段

- 同步段、传播段、相位缓冲段 1、相位缓冲段 2 各自的职责
- 一张位时间分解示意图

### 2.3、采样点的物理含义

- 采样发生在哪两段之间，为什么不是在位中间
- 采样点偏前与偏后各自会先暴露什么问题

### 2.4、传播段为什么必须存在

- 信号在总线上往返一次的时间必须落在一个位内
- 与 v0.2〈瓶颈二：速率被仲裁卡住〉的关系：那里讲结论与长度表，这里讲它如何落到传播段的取值上

### 2.5、同步：硬同步与重同步

- 帧起始处的硬同步与位边沿的重同步，分别在什么时候发生
- 重同步能修正多少，由哪个参数限定

### 2.6、贯穿案例的位时间分解

- 按案例的时钟源与目标速率，画出一个位的完整分解
- 标出采样点位置，作为第三章计算的起点

## 第三章、位时序参数与采样点

> 本章解决的工程决策：给定时钟源与目标波特率，算出一组所有节点都能用的位时序参数。

### 3.1、从目标波特率反推参数

- 完整计算流程：确定时钟源 → 选预分频 → 分配各段量子数 → 校验采样点
- 为什么同一个波特率有多组解，以及怎么在多组解中挑选

### 3.2、采样点怎么选

- 选择依据：总线长度、节点数量、时钟精度、是否有隔离
- 仲裁段与数据段的经验区间不同，回指 v0.2〈分层检查清单〉里的取值
- 采样点选错的典型表现，以及它在第五章对应哪类错误

### 3.3、同一网络内的一致性要求

- 为什么"波特率一样"不够，回指 v0.1〈位时序和波特率〉提出但未展开的问题
- 哪些参数必须各节点严格一致，哪些允许存在差异
- 不同厂商控制器的段划分与寄存器命名差异，如何换算成统一口径

### 3.4、控制器寄存器差异

- 常见的几类寄存器组织方式与它们和标准段名的对应关系
- 从"标准参数"到"具体寄存器值"的换算注意事项：是否需要减一、传播段是否与相位段合并

### 3.5、贯穿案例：算出一组可用配置

- 完整演算过程，从时钟源一路到寄存器值
- 同时给出一组"看起来也对但不推荐"的解及其问题

### 3.6、算不出来怎么办

- 三个旋钮：换时钟源、改预分频与段分配、调整目标波特率
- 每个旋钮的代价与适用条件
- 什么情况下必须回头改硬件

> 本章产出：**位时序配置表**，含各节点的时钟源、预分频、段分配、采样点与对应寄存器值。

## 第四章、时钟容差、SJW 与 FD 的两套时序

> 本章解决的工程决策：这组参数能容忍多大的时钟偏差，以及 CAN FD 的数据段还要额外配什么。

### 4.1、时钟偏差从哪里来

- 晶振标称精度、温漂、老化、负载电容不当
- 内部 RC 振荡器为什么通常不能用于 CAN，回指 v0.2〈分层检查清单〉的时钟源要求

### 4.2、同步跳转宽度的作用与约束

- 它允许重同步修正多少，取值上限由哪些段限定
- 取大与取小各自的代价

### 4.3、时钟容差核算

- 核算方法：由段分配与跳转宽度反推可容忍的偏差比例
- 把核算结果与晶振实际精度对比，判断裕量是否足够
- 裕量不足时的处理顺序

### 4.4、FD 的标称段与数据段

- 两套位时序各自约束什么，为什么数据段可以不受总线长度限制
- 两套时序的采样点通常不同，原因是什么
- 只配了一套时序的典型表现，回指 v0.2〈容易出问题的点〉

### 4.5、发送器延迟补偿与二次采样点

- 数据段速率提高后，环回延迟为什么会超过一个位时间
- 二次采样点的作用与配置方式
- 未配置或配置不当的表现，以及它与数据段 CRC 错误的关系

### 4.6、贯穿案例：数据段配置与容差核算

- 按案例的数据段速率算出第二套参数
- 完成两套时序的容差核算，给出裕量结论

> 本章产出：**时钟容差核算表**，含两套位时序参数、可容忍偏差、实际晶振精度与裕量判定。

## 第七章、从单帧时长到总线负载与实时性

- 按周期报文累加的方法，事件报文如何估计

### 7.4、最坏响应时间分析

- 三个组成部分：阻塞时间、排队延迟、传输时间

### 7.5、错误与重传的影响

### 7.6、负载或时限不满足怎么办

- 旋钮清单：调整周期、合并报文、重新分配 ID 优先级、提高数据段速率、拆分总线

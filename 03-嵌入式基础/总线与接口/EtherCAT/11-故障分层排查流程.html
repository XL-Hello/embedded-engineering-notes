调试工具（7.3）

  • • 主站自带工具（TwinCAT System Manager、ethercat 命令行）
  • • Wireshark（带 EtherCAT 解析器）
  • • ESC 寄存器读取（SM/FMMU/DC/错误计数器）
  • • 网络分接器 TAP（不破坏时序旁路抓包）
  • • 示波器验证 SYNC0 对齐（验证DC是否真正工作最直接）

CRC 错误定位方法

  • • 沿拓扑看各端口错误计数器（RX/转发RX/Lost Link）
  • • 错误开始累加的那个端口的上游链路就是问题所在
  • • 常见诱因：线缆质量差/超长、接头氧化松动
  • • 常见诱因：强干扰、屏蔽层没接好、拖链线缆疲劳

高频故障 TOP3

  • • PDO 映射长度不一致 → 0x001D / 0x001E
  • • SyncManager 看门狗超时 → 0x001B
  • • DC 同步不上 → 0x0030 / 0x0032

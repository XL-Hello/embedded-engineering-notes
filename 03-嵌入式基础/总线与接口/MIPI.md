# MIPI 系列文档导读

MIPI 这个主题按**工程阶段**拆成三篇，而不是按知识点深浅拆。判断自己该看哪一篇，只需要回答一个问题：**你现在卡在哪一步？**

| 文档 | 标题 | 回答的问题 | 适用阶段 |
| --- | --- | --- | --- |
| [MIPI_v0.1.md](MIPI_v0.1.md) | MIPI 基础知识总结 | 它是什么、CSI 和 DSI 有什么区别、有哪些模式、为什么这样选 | 入门、面试复习、快速建立概念 |
| [MIPI_v0.2.md](MIPI_v0.2.md) | MIPI DSI 进阶：链路预算、传输语法与 Bring-up 调试 | 参数怎么算、链路上到底传了什么、面板如何初始化、怎样把新屏稳定点亮、异常怎么定位 | 手上有一块屏要点亮或有故障要查 |
| [MIPI_v0.3.md](MIPI_v0.3.md) | MIPI DSI 落地：从选型到量产交付 | 怎么把它做成可追溯、可验证、可批量交付的产品 | 样机已点亮，要走向出货 |

三篇的交接点很清晰：

```text
v0.1 终点：知道该选 Video Mode 还是 Command Mode
        ▼
v0.2 起点：这块屏的参数怎么算、怎么点亮
v0.2 终点：实验室里样机首帧正常、错误计数为零
        ▼
v0.3 起点：样机亮了，但选型论证、硬件约束、电气裕量、参数架构、验证矩阵都还没做
v0.3 终点：一份可签字归档的出货判据
```

## 覆盖范围差异

- **v0.1** 同时覆盖 CSI-2 和 DSI，偏概念对比与排查思路，不展开计算。
- **v0.2** 只做 DSI + D-PHY，围绕一次完整 Bring-up 组织：传输模型 → 链路预算 → 协议包 → 面板控制 → 最小点亮路径 → 调试闭环。全文用同一块 800×1280 教学面板贯穿。
- **v0.3** 只服务"交付一个 DSI 显示产品"，内容是选型论证、原理图/PCB 评审、PHY 裕量、参数归属与多面板架构、量产验证矩阵。沿用 v0.2 那块面板，场景升级为要出货的产品。

## 使用建议

- 第一次接触 MIPI：按 v0.1 → v0.2 顺读。
- 项目里要点一块新屏：直接进 v0.2，从它的 Bring-up 章节反查。
- 已经出现花屏、黑屏、偶发失败：进 v0.2 的调试闭环章节，按症状分层。
- 产品要过评审或出货：进 v0.3。

## 第一阶段：C++ 核心基础

基础巩固

### 1.1 C 与 C++ 的核心差异

- C++ 编译模型、命名空间 `namespace`
- 引用 `&` 与指针的区别
- `const`、`constexpr` 基础
- 函数重载、默认参数
- `inline`、`auto`、`decltype`
- `nullptr` 与 `NULL`

### 1.2 类与对象

- `class` 与 `struct` 的区别
- 访问控制：`public`、`private`、`protected`
- 成员变量、成员函数
- `this` 指针
- 静态成员 `static`
- 成员初始化列表
- `const` 成员函数

### 1.3 对象生命周期

- 构造函数、析构函数
- 拷贝构造、拷贝赋值
- 深拷贝与浅拷贝
- 对象的创建与销毁顺序
- 栈对象、堆对象、静态对象
- `new/delete` 与 `malloc/free`

阶段目标： 理解 C++ 如何通过对象管理数据和资源。

## 第二阶段：面向对象与资源管理

基础巩固

### 2.1 面向对象

- 封装、继承、多态
- 虚函数 `virtual`
- 纯虚函数、抽象类
- 虚析构函数
- `override`、`final`
- 静态绑定与动态绑定
- 虚函数表 vtable、虚指针 vptr（常见实现机制）
- 对象切片、多重继承

### 2.2 资源管理

- RAII 思想
- Rule of Three / Five / Zero
- 异常处理 `try/catch/throw`
- 异常安全保证
- 构造与析构中的异常问题
- `noexcept`

### 2.3 运算符重载

- 常见运算符重载
- 拷贝赋值、移动赋值
- `explicit` 构造函数
- 类型转换运算符

阶段目标： 能设计可靠的 C++ 类，理解资源为什么应该跟随对象生命周期管理。

- `deque`、`list`

## 第五阶段：C++17 新特性

核心学习阶段

### 5.1 语言语法

- 结构化绑定 `auto [a, b]`
- `if constexpr`
- `if/switch` 初始化语句
- 内联变量 `inline variables`
- 折叠表达式（Fold Expressions）
- 类模板实参推导（CTAD）
- `constexpr` Lambda
- `if constexpr` 与模板编译期分支

### 5.2 新增标准库

- `std::optional`：可选值
- `std::variant`：类型安全的联合体
- `std::any`：任意类型容器
- `std::string_view`：非拥有型字符串视图
- `std::filesystem`：文件和目录操作
- `std::byte`：字节类型
- `std::invoke`：统一调用接口
- `std::apply`：展开元组调用函数

### 5.3 C++17 泛型增强

- `std::visit`
- `std::void_t`
- `std::is_same_v` 等 `_v` 类型萃取
- `std::conjunction`、`std::disjunction`
- `std::optional` 与错误处理设计
- 编译期分支与模板实例化

### 5.4 C++17 性能相关特性

- `std::pmr` 多态内存资源
- `std::hardware_destructive_interference_size`
- `std::hardware_constructive_interference_size`
- `std::shared_mutex`（C++17）
- `std::scoped_lock`
- 并行算法基础

阶段目标： 能理解 C++17 相比 C++11/14 解决了什么问题，并在实际项目中合理使用。

## 学习重点建议

考虑到你主要从事嵌入式软件开发，我建议把精力集中在以下五个知识方向：

1. 对象生命周期与 RAII：从 C 转向 C++ 最关键的思维变化。
2. 移动语义与智能指针：理解资源所有权，减少内存管理错误。
3. STL 容器与模板：掌握现代 C++ 最常用的开发工具。
4. C++17 核心特性：重点学习 `optional`、`variant`、`string_view`、结构化绑定、`if constexpr`。
5. 多线程与内存模型：与 Linux、RTOS、设备通信等实际项目关联最紧密。

## 图 5

图序“5、”，标题“运算符与显式转换”。三栏：“符合直觉” 代码 Sample& operator+=(const Sample& other); / Sample operator+(Sample left, const Sample& right); / bool operator==(const Sample& left, const Sample& right); 说明：+ 表示相加，== 表示等价；不能改变优先级、结合性、操作数数量。“赋值管理资源” 复制赋值：复制资源或成员状态；移动赋值：转移资源；通常返回 *this 的引用；检查旧资源释放、自赋值、失败状态；优先 Rule of Zero。“控制转换” 代码 explicit Port(int number); / explicit operator bool() const; 然后三条标记：Port p = 1; 禁止隐式转换（叉）；Port p{1}; 直接初始化（勾）；if (p) { ... } 条件判断（勾）。底部提示：“不要把设备发送藏进意外的算术表达式；显式有效性判断可避免意外整数转换。”

# 1. C / 编译 / 链接 / 启动链路

## 1.1 编译流程

```text
.c → .o → .elf → .bin/.hex → 烧录 → 运行
```

### 编译（Compile）

* C 代码 → 汇编 → 机器码
* 生成 `.o`
* 包含：代码 + 符号 + 重定位信息

---

### 链接（Link）

* 多个 `.o` + 库 → `.elf`
* 作用：

  * 合并代码段
  * 解析函数调用
  * 分配地址

---

### 重定位（Relocation）

* 把“未知地址”补成“真实地址”
* 解决：

  * 函数调用地址
  * 全局变量地址

---

## ELF / BIN / HEX

| 文件  | 特点          | 用途 |
| --- | ----------- | -- |
| ELF | 完整信息（符号+调试） | 调试 |
| BIN | 纯二进制        | 烧录 |
| HEX | 带地址的文本格式    | 烧录 |

# 2. Boot 流程（Bootloader / U-Boot / BSP）

## 2.1 Bootloader 是什么

> 芯片上电后第一个运行的软件

职责：

```text
硬件初始化
加载系统
校验镜像
跳转执行
```

---

## 2.2 U-Boot

* Bootloader 的一种实现
* 常用于 Linux SoC

作用：

```text
初始化 DDR / Flash
加载 Linux kernel + dtb
设置启动参数
跳转内核
```

---

## 2.3 BSP

> 板级支持包

内容：

```text
时钟 / GPIO / UART / DDR / Flash 驱动
设备树
板级配置
```

---

## 关系

```text
Bootloader 使用 BSP 初始化硬件
U-Boot 是 Bootloader 的一种实现
```

---

## 启动链路

### Linux：

```text
Boot ROM → U-Boot → Linux → rootfs → app
```

### RTOS：

```text
Boot ROM → Bootloader → RTOS
```

### 裸机：

```text
Boot ROM → APP（可选 Bootloader）
```

# 3. 中断 / 串口 / printf

## 3.1 中断延迟

组成：

```text
硬件响应 + 当前指令 + 关中断时间 + ISR执行时间
```

---

## 测量方法

* GPIO 翻转 + 示波器（最准确）
* Timer 计数
* RTOS trace

---

## 优化

```text
减少关中断时间
ISR只做最少工作
使用DMA
降低中断频率
```

---

## 串口中断发送原理

```text
应用写 buffer
→ UART TX中断触发
→ ISR逐字节发送
→ buffer空则关闭中断
```

---

## printf 到串口问题

关键点：

```text
串口慢 + printf重 + 多任务冲突
```

必须考虑：

* ring buffer
* DMA/中断发送
* mutex保护
* 限流
* 分级日志

# 4. 内存管理

## 4.1 内存泄漏

> malloc 后没有 free

后果：

```text
内存不断下降 → malloc失败 → 系统崩溃
```

---

## 定位方法

```text
观察 heap变化
封装 malloc/free
对比操作前后内存
查异常 return 路径
```

---

## 避免方法

```text
统一释放路径
减少动态内存
明确所有权
```

# 8. 调度算法

## 8.1 轮转调度

```text
任务自己让出CPU
```

优点：简单
缺点：实时性差

---

## 8.2 优先级抢占

```text
高优先级抢占低优先级
```

优点：实时性强
缺点：可能饿死

---

## 8.3 时间片轮转

```text
每个任务固定时间片
```

优点：公平
缺点：切换开销

---

# 9. RTOS IPC机制

## 9.1 信号量

```text
计数/事件通知
```

用途：

* 中断通知任务
* 资源计数

---

## 9.2 互斥锁

```text
保护共享资源
```

特点：

* 有所有权
* 防止并发冲突

---

## 9.3 消息队列

```text
任务间传递数据
```

用途：

* 生产者消费者
* 解耦模块

---

## 9.4 事件标志组

```text
多个bit表示状态
```

用途：

* 多条件同步
* 状态组合

---

## 对比总结

| 机制   | 本质    | 是否传数据 |
| ---- | ----- | ----- |
| 信号量  | 计数/同步 | ❌     |
| 互斥锁  | 资源保护  | ❌     |
| 消息队列 | 数据通信  | ✅     |
| 事件组  | 状态管理  | ❌     |

# 13. 可重入 vs 线程安全

## 可重入

```text
函数被打断再次进入不会错
```

特点：

* 不用全局变量
* 不用静态变量

---

## 线程安全

```text
多线程调用不会出错
```

实现：

* 可以用锁

---

## 区别

```text
可重入 ≠ 一定线程安全
线程安全 ≠ 一定可重入
```
